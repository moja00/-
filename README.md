# BillCraft (ビルクラフト) - 納品書・請求書 かんたん発行アプリ

直感的で美しい操作画面から、インボイス制度（適格請求書）対応の納品書・請求書・見積書・領収書をすばやく作成・印刷（PDF保存）できるアプリです。
Windows と Mac のどちらでもそのままご利用いただけます。

---

## 🚀 起動方法

### 【Mac をお使いの場合】
1. フォルダ内の **`start.command`** をダブルクリックします。
2. 自動的にブラウザ（Google Chrome等）が開き、アプリが起動します。
   *(※または `index.html` を直接ブラウザにドラッグ＆ドロップでも起動できます)*

### 【Windows をお使いの場合】
1. フォルダ内の **`start.bat`** をダブルクリックします。
2. 自動的にブラウザ（Microsoft Edge または Google Chrome）が開き、アプリが起動します。
   *(※または `index.html` を直接ダブルクリックでも起動できます)*

## ✨ 主な機能と特徴

### 1. 4大帳票のワンクリック切り替え
- **請求書**（御請求書）
- **納品書**（納品書）
- **見積書**（御見積書）
- **領収書**（領収証）
同じ明細データを保持したまま、上部のボタンを切り替えるだけで相互に変換できます。

### 2. インボイス制度（適格請求書）完全対応
- 発行事業者登録番号（`T+13桁`）の入力・印字に対応
- 税率（10%標準・8%軽減税率・非課税）ごとの税抜小計・消費税額を法令に則って自動集計
- 消費税の端数処理（切り捨て、四捨五入、切り上げ）の切り替えに対応

### 3. 本格的な電子角印（社印）自動生成
- 会社名・屋号を入力して「角印を自動生成」ボタンを押すだけで、朱色の本格的な角印スタンプが自動描画されます。
- お手持ちの社印・角印の画像ファイル（PNG/JPEG）をアップロードして押印することも可能です。

### 4. 高精度なA4用紙・PDF印刷
- 画面上の「**PDF保存・印刷**」ボタン、またはショートカット（Mac: `Cmd + P` / Windows: `Ctrl + P`）を押すだけで、ブラウザの印刷ダイアログからA4縦サイズぴったりの美しいPDFを書き出せます。
- 余分な入力欄やボタンは印刷時には自動で消えるため、プレビュー通りの帳票に仕上がります。

### 5. 自社情報＆履歴の自動保存
- 自社名・インボイス番号・住所・振込先口座はブラウザ内に安全に保存されるため、次回作成時にも自動入力されます。
- 作成した書類は「履歴に保存」ボタンでいつでも呼び出し・再編集・複製が可能です。

### 6. データ管理・バックアップ
- 「データ管理」メニューから、自社情報や過去の作成履歴を1つのファイル（JSON形式）としてダウンロードできます。
- パソコンを買い替えた際や、別のパソコン（Mac ↔ Windows）へデータを引き継ぎたい場合も、JSONファイルを読み込むだけでかんたんに移行できます。

## 🔒 セキュリティ・プライバシー
入力された請求内容・取引先情報・金額・口座情報は、**すべてお使いのパソコンのブラウザ内（ローカル）にのみ保存**されます。外部のサーバーへ送信されることは一切ありませんので、安心してご利用いただけます。
